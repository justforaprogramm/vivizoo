# Dependencies of the backend module.
#
# The backend itself is pure standard library. It talks to the database
# module (db/) through its public contract, and the database module needs
# SQLAlchemy. Install everything from the repository root, inside the
# devcontainer:
#
#     pip install -r backend/requirements.txt
#
# Q: Why does the backend list SQLAlchemy?
# A: Not because the backend uses it directly, but because it depends on the
#    db package (via backend.persistence.db_gateway importing
#    db.interface.AbstractPersistence and db.models). Keeping the dependency
#    listed here makes the backend's requirements self-contained.

SQLAlchemy>=2.0,<3.0

#     pip install -r backend/requirements.txt --extra-index-url ... (oder:)
#     pip install pytest
pytest>=7.0
