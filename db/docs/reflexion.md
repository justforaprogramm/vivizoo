# AI Reflection

**Focus: Database. Module lead: Jannes.**

> **Authorship.** This text was written by hand, without AI assistance —
> the only file in this module to be so. That's precisely the point: the process facts
> are documented in [`ai_usage.md`](ai_usage.md) and can be verified against the repository,
> but the reflection on that process is something no one can delegate.

Initially, I created a one-shot version that still contained quite a few errors. I then went through and corrected it, testing each function individually. Once everything was working correctly, I also had the documentation generated by AI and cross-checked it against the actual implementation. After that, I had AI run another round of tests against various criteria, and finally reviewed everything once more as a whole. One key takeaway is that AI sometimes makes fairly significant mistakes, so next time I'll work more incrementally, step by step, it's simply less stressful and saves me from having to fix one huge batch of errors at the end.
